# Docks Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Independent, typed Frame docks with an interactive documentation playground.

**Architecture:** A per-Frame dock controller owns registrations, placement, visibility and disposal. Shell-owned dock regions reserve space outside an anchor; inside regions reserve space in an internal content grid. Top/bottom lanes own shared corners. Persistent teleported surfaces preserve component identity across moves. Outside sidebar/view-bar contributions surround the combined region to keep the pair together.

**Tech Stack:** Vue, TypeScript, Frame theme tokens, Bun and Playwright.

**Spec:** User-approved dock model in this conversation: logical anchors and physical edges, edge-axis stretching, content-sized cross axis, optional explicit dimensions, selectable normal/small/no padding, small theme gap and rounded corners in normal density, touching square edges in compact density. Hidden anchors retain a collapsed attachment point; disabled anchors suppress docks. Content is application-owned.
