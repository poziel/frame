# Dropdown Menus

Command menus with separators, disabled choices, and nested submenus.

## Features

### Choose a project action

A dropdown keeps related actions behind one trigger. Disabled actions remain visible but cannot be selected.

<!-- frame:example id="menus.task-0" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameDropdownMenu } from '@frame/core';
const demoItems = [
  {
    "id": "new",
    "label": "New file",
    "shortcut": "Ctrl+N"
  },
  {
    "id": "save",
    "label": "Save project",
    "shortcut": "Ctrl+S"
  },
  {
    "id": "remote",
    "label": "Publish remotely",
    "disabled": true
  }
];
</script>
<template>
<FrameDropdownMenu :trigger-label="&quot;Project actions&quot;" :items="demoItems" />
</template>
```

### Choose an export action

Use a compact menu for related export commands rather than placing every action in the toolbar.

<!-- frame:example id="menus.task-1" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameDropdownMenu } from '@frame/core';
const demoItems = [
  {
    "id": "archive",
    "label": "Download archive"
  },
  {
    "id": "clipboard",
    "label": "Copy summary"
  }
];
</script>
<template>
<FrameDropdownMenu :trigger-label="&quot;Export&quot;" :items="demoItems" />
</template>
```

#### Properties
