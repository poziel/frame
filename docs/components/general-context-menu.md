# Context Menu

A themed context menu powered by Reka UI.

## Features

### Act on a resource

Right-click the trigger region to see commands for the current resource; the host receives the selected action.

<!-- frame:example id="general-context-menu.task-0" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameContextMenu } from '@frame/core';
const demoItems = [
  {
    "id": "new",
    "label": "New file",
    "shortcut": "Ctrl+N"
  },
  {
    "id": "save",
    "label": "Save project",
    "shortcut": "Ctrl+S"
  },
  {
    "id": "remote",
    "label": "Publish remotely",
    "disabled": true
  }
];
</script>
<template>
<FrameContextMenu :trigger-label="&quot;Right-click project&quot;" :items="demoItems" />
</template>
```

### Offer focused file commands

A resource-specific menu can expose only the commands relevant to the selected file.

<!-- frame:example id="general-context-menu.task-1" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameContextMenu } from '@frame/core';
const demoItems = [
  {
    "id": "open",
    "label": "Open file"
  },
  {
    "id": "rename",
    "label": "Rename file"
  }
];
</script>
<template>
<FrameContextMenu :trigger-label="&quot;Right-click file&quot;" :items="demoItems" />
</template>
```
