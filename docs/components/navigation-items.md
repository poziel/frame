# Navigation Items

Actions, links, menus and separators in the navigation bar.

## Features

### Basic usage

Navigation items are independent of sidebar and panel views. Register them explicitly; the host owns actions and destinations. The navigation bar can dock on any edge.

<!-- frame:example id="navigation-items.basic" -->

```vue
frame.registerNavigationItem({ id: 'home', type: 'link', label: 'Home', href: '#/home' });
```

### Composition and configuration

Compose this API with application-owned content. Use the actions in this example to inspect the behavior.

<!-- frame:example id="navigation-items.configured" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { NavigationBar } from '@frame/core';

</script>
<template>
<NavigationBar  />
</template>
```
