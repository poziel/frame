# FrameForm

A form container that coordinates registered fields, validation, server errors, and submission. The host performs saving and backend requests.

## Features

### Anatomy

```text
FrameForm
FormRoot (native form by default)
└─ default slot: application fields and submit/reset controls
```

Caller attributes/class/style reach FormRoot and its native form. The default slot is passed through without a scoped payload. These Reka parts are internal composition, not separately exported Frame building blocks.

### Basic usage

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { FrameForm, FrameTextInput, FrameField, FrameButton } from '@frame/core';
import '@frame/core/style.css';

const value = ref('');
const saved = ref('');
function save(values: Record<string, unknown>) {
  saved.value = JSON.stringify(values);
}
</script>

<template>
  <FrameForm @form-submit="save">
    <FrameField name="projectName" label="Project name" required>
      <FrameTextInput v-model="value" />
    </FrameField>
    <FrameButton type="submit">Save</FrameButton>
    <p role="status">{{ saved }}</p>
  </FrameForm>
</template>
```

Load the stylesheet once per application. This component works without a Frame instance.

### Submission and registered values

`@form-submit` receives a values object and the native SubmitEvent. Listening to it prevents navigation. The object contains named registered fields, not an automatic FormData scan of every descendant. Use distinct field names. Controls outside FrameField do not automatically become registered value entries just by having a native name.

`@submit` receives a SubmitEvent only after synchronous field validation succeeds. With only this listener, call `event.preventDefault()` (or use `.prevent`) for application-handled saving; otherwise native submission can continue to the form’s action. When any registered field is invalid, submission is prevented, no success event is emitted, and the first invalid control is focused in document order.

### Server errors, reset, and validation timing

`errors` is a record keyed by field name with string or string-array messages. Matching fields display those errors until the field is edited or new server errors arrive. Errors arriving after a submit can focus the first affected control. `validationMode` defaults to `onSubmit`; fields can override it.

FormRoot sets `novalidate` and coordinates native constraints through its registered fields. Async field validators cannot hold up native submission; perform required asynchronous acceptance checks in the host handler before saving. Native reset notifies registered fields; coordinate host-controlled Vue values when implementing a reset action. FrameForm has no saving/loading state or backend behavior.

### Composition and accessibility

Use actual submit buttons and one FrameField per named input. Native form attributes such as action, method, autocomplete, and aria-label fall through. Changing `as` away from a form also changes native submission semantics; retain the default for ordinary forms. Reka’s ref-level validate method is not forwarded by FrameForm.


## APIs

Defaults below are Reka reference defaults unless a Frame override is stated. Declared means a typed Frame prop/event; Forwarded means attribute/listener fallthrough to the named part; Internal means generated by Frame; Absent means not routed or composed. Generic upstream `T`/`AcceptableValue` describes Reka, not a promise of arbitrary option values in Frame.

### Root

#### Props

| Prop | Reka type | Reka required/default | Availability | Frame behavior |
| --- | --- | --- | --- | --- |
| `as` | `AsTag \| Component` | "form" | Declared | Element/component used to render this part. |
| `asChild` | `boolean` | - | Declared | Merge behavior into the single child supplied through the default slot. |
| `errors` | `Record<string, string \| string[]>` | - | Declared | Server messages keyed by registered field name. |
| `validationMode` | `"onBlur" \| "onChange" \| "onSubmit"` | "onSubmit" | Declared | Choose change, blur, or submit-triggered validation. |

#### Emits

| Event | Payload | Availability | Behavior |
| --- | --- | --- | --- |
| `formSubmit` | `[values: Record<string, unknown>, event: SubmitEvent]` | Declared | Validated registered field values and native submit event; attaching this listener prevents native navigation. |
| `submit` | `[event: SubmitEvent]` | Declared | Edit commit or validated form submission; see Features for the native SubmitEvent cancellation rules. |

#### Slots

Underlying default content has no documented scoped fields. Frame passes caller content through without a payload.

#### Data attributes

No component state data attributes are defined on this part. Inherited native/ARIA attributes are not data attributes.

#### Exposed methods

Frame does not defineExpose or forward the internal Reka instance. Reka’s validate(fieldName?: string): boolean is therefore not a FrameForm ref method.

### Frame additions

#### Props

No Frame-only props.

#### Emits

No additional Frame-only events; see the part tables for declared or forwarded events.

#### Slots

`default`: application form content; no scoped payload.
