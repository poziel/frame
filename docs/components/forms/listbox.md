# FrameListbox

An always-visible list of string options with single or multiple selection and keyboard navigation.

## Features

### Anatomy

```text
FrameListbox
ListboxRoot
└─ ListboxContent (role=listbox)
   ├─ ListboxItem × options (label + optional detail)
   └─ div[role=separator] × separators
```

Caller attributes/class/style reach the outer Root. Content owns role=listbox and its own focus/navigation attributes; Root attributes are not automatically copied there. These Reka parts are internal composition, not separately exported Frame building blocks.

### Basic usage

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { FrameListbox, type SelectItem } from '@frame/core';
import '@frame/core/style.css';

const value = ref<string[]>(['vue']);
const options: SelectItem[] = [
  { value: 'vue', label: 'Vue', detail: 'Frontend' },
  { type: 'separator', id: 'other' },
  { value: 'rust', label: 'Rust' },
  { value: 'legacy', label: 'Unavailable', disabled: true },
];
</script>

<template>
  <FrameListbox v-model="value" :options="options" multiple label="Languages" />
</template>
```

Load the stylesheet once per application. This component works without a Frame instance.

### Options and multiple selection

Options have a unique string `value`, visible `label`, optional `detail`, `description`, and `disabled`; separators have `type: 'separator'` and `id`. Frame renders label/detail, not description. All rows are generated; there is no item template, filter input, virtualization, or custom empty-state slot.

Set `multiple` and bind `string[]` for multiple selection; bind a string for single selection. The wrapper declares a union without enforcing consistency. Reka’s `selectionBehavior` defaults to `toggle`; forwarding `selection-behavior="replace"` changes multi-selection gestures. A controlled model must be updated by the host.

### Keyboard and accessibility

Content owns role=listbox. Arrow keys navigate according to orientation, Home/End move to endpoints, and Enter selects the highlighted item. Reka provides typeahead and multi-selection gestures. Disabled options are skipped. Selection (`data-state`) and highlight (`data-highlighted`) are distinct; Frame styles both with the accent background.

`label` currently names the outer Root, not the inner role=listbox Content. There is no public Content attributes slot; do not assume this alone gives the inner listbox an accessible name. Include visible context and verify the rendered accessibility tree for the host use case. Root orientation changes navigation semantics, while Frame’s Content layout remains a column.

### Forms

Root `name` and `required` may be forwarded to Reka’s native helper integration; they are not declared Frame props. Disabled state reaches Root and every generated option. Frame does not expose an associated-form prop or reset API; keep the host selection synchronized when resetting a form.

## APIs

Defaults below are Reka reference defaults unless a Frame override is stated. Declared means a typed Frame prop/event; Forwarded means attribute/listener fallthrough to the named part; Internal means generated by Frame; Absent means not routed or composed. Generic upstream `T`/`AcceptableValue` describes Reka, not a promise of arbitrary option values in Frame.

### Root

| Prop                | Reka type                                                         | Reka required/default | Availability | Frame behavior                                                                                                                                                                  |

Frame always supplies modelValue, so this does not initialize wrapper state.                |

Disable interaction for this part and its participating descendants.                                                                                   |

#### Emits

| Event               | Payload                                                                | Availability | Behavior                                                                                                     |
| ------------------- | ---------------------------------------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------ |

| `highlight`         | `[payload: { ref: HTMLElement; value: AcceptableValue } \| undefined]` | Forwarded    | Active highlighted item changed; includes its element and value, or undefined when cleared. Not cancellable. |
| `leave`             | `[event: Event]`                                                       | Forwarded    | Pointer left the listbox container.                                                                          |
| `update:modelValue` | `[value: string \| string[]]`                                          | Declared     | Value changed; retain it in host state. Not cancellable. Payload shown is Frame’s public payload.            |

| Default-slot field | Reka type               | Frame availability                             |
| ------------------ | ----------------------- | ---------------------------------------------- |
| `modelValue`       | `T \| T[] \| undefined` | Internal; not passed to the Frame caller slot. |

#### Data attributes

| Attribute       | Values/presence         | Meaning                      |
| --------------- | ----------------------- | ---------------------------- |
| `data-disabled` | `Present when disabled` | Inherited ListboxRoot state. |

#### Exposed methods

Frame does not defineExpose or forward the internal Reka instance. Do not depend on internal Reka methods/refs through a Frame component ref.

### Omitted parts

`Filter`, `ItemIndicator`, `Group`, `GroupLabel`, `Virtualizer` are not rendered by this wrapper. Their props, slots, presence controls, and composition APIs are not available through Frame. See the [Reka reference](https://reka-ui.com/docs/components/listbox).

### Frame additions

#### Props

| Prop      | Type                    | Required/default | Description                                             |
| --------- | ----------------------- | ---------------- | ------------------------------------------------------- |
| `options` | `readonly SelectItem[]` | Required         | Generated option rows and separators.                   |
| `label`   | `string`                | Unset            | aria-label on the outer Root; see accessibility limits. |

#### Emits

No additional Frame-only events; see the part tables for declared or forwarded events.

#### Slots

No public content slots; all internal children are generated.
