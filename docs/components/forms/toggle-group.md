# FrameToggleGroup

A collection of pressed-state buttons generated from string options, useful for selecting formatting or display modes.

## Features

### Anatomy

```text
FrameToggleGroup
ToggleGroupRoot
├─ ToggleGroupItem × options (label + optional detail)
└─ div[role=separator] × separators
```

Caller attributes/class/style reach Root. Items and separators are generated; no caller content slots are rendered. These Reka parts are internal composition, not separately exported Frame building blocks.

### Basic usage

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { FrameToggleGroup, type SelectItem } from '@frame/core';
import '@frame/core/style.css';

const value = ref<string[]>(['vue']);
const options: SelectItem[] = [
  { value: 'vue', label: 'Vue', detail: 'Frontend' },
  { type: 'separator', id: 'other' },
  { value: 'rust', label: 'Rust' },
  { value: 'legacy', label: 'Unavailable', disabled: true },
];
</script>

<template>
  <FrameToggleGroup v-model="value" :options="options" label="Enabled languages" />
</template>
```

Load the stylesheet once per application. This component works without a Frame instance.

### Single and multiple values

For single selection, bind a string. For multiple selection, initialize a string array as in Basic usage. Reka infers its selection mode from model/default shape or a forwarded `type="single"`/`"multiple"`. Frame’s `multiple` boolean is not read by Reka’s ToggleGroupRoot; it must not be relied on as the mode switch. Deselecting the active single item can emit an empty string.

Options use unique string values, labels, optional detail/description, and disabled flags; separators use type=separator and id. Frame renders label and detail, not description. Option buttons and separators have no caller templates. Keep model shape consistent with the chosen mode.

### Keyboard, accessibility, and forms

Root is a named group. Each generated button exposes aria-pressed and data-state=on/off. Roving focus and wrapping are enabled by default; arrow keys move focus according to orientation, while Space/Enter toggles the focused item. Disabled options cannot activate. Changing keyboard orientation does not change Frame’s wrapping flex layout.

Root `name`/`required` are forwarded to Reka’s native hidden-input integration; the wrapper does not add a form association or reset API. Selection and application persistence remain host-owned.

## APIs

Defaults below are Reka reference defaults unless a Frame override is stated. Declared means a typed Frame prop/event; Forwarded means attribute/listener fallthrough to the named part; Internal means generated by Frame; Absent means not routed or composed. Generic upstream `T`/`AcceptableValue` describes Reka, not a promise of arbitrary option values in Frame.

### Root

#### Props

| Prop           | Reka type                              | Reka required/default | Availability | Frame behavior                                                                                                                                                           |
| -------------- | -------------------------------------- | --------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `as`           | `AsTag \| Component`                   | "div"                 | Forwarded    | Element/component used to render this part.                                                                                                                              |
| `asChild`      | `boolean`                              | -                     | Forwarded    | Reaches Root, but Frame supplies fixed internal children; no public composition contract for replacing them.                                                             |
| `defaultValue` | `AcceptableValue \| AcceptableValue[]` | -                     | Forwarded    | Initial uncontrolled value upstream; does not override a supplied controlled model. Frame always supplies modelValue, so this does not initialize wrapper state.         |

| `disabled`     | `boolean`                              | false                 | Declared     | Frame: `boolean`, false. Disable interaction for this part and its participating descendants.                                                                            |
| `loop`         | `boolean`                              | true                  | Forwarded    | Wrap keyboard navigation at collection endpoints.                                                                                                                        |
| `modelValue`   | `AcceptableValue \| AcceptableValue[]` | -                     | Changed      | Frame: `string \| string[]`, Required. Controlled value; updates require the host to retain the emitted value. No runtime normalization; upstream mode can change shape. |

#### Emits

| Event               | Payload                       | Availability | Behavior                                                                                          |
| ------------------- | ----------------------------- | ------------ | ------------------------------------------------------------------------------------------------- |
| `update:modelValue` | `[value: string \| string[]]` | Declared     | Value changed; retain it in host state. Not cancellable. Payload shown is Frame’s public payload. |

#### Slots

| Default-slot field | Reka type                                           | Frame availability                             |
| ------------------ | --------------------------------------------------- | ---------------------------------------------- |
| `modelValue`       | `AcceptableValue \| AcceptableValue[] \| undefined` | Internal; not passed to the Frame caller slot. |

#### Data attributes

No component state data attributes are defined on this part. Inherited native/ARIA attributes are not data attributes.

#### Exposed methods

Frame does not defineExpose or forward the internal Reka instance. Do not depend on internal Reka methods/refs through a Frame component ref.

### Item

#### Props

| Prop       | Reka type            | Reka required/default | Availability | Frame behavior                                                                                                       |
| ---------- | -------------------- | --------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------- |
| `as`       | `AsTag \| Component` | "button"              | Internal     | Element/component used to render this part. Not independently configurable through Frame.                            |
| `asChild`  | `boolean`            | -                     | Internal     | Merge the part behavior into one child instead of rendering a wrapper. Not independently configurable through Frame. |
| `disabled` | `boolean`            | -                     | Internal     | Derived from root/option disabled state. Not independently configurable through Frame.                               |
| `value`    | `AcceptableValue`    | Required upstream     | Internal     | Derived from option.value. Not independently configurable through Frame.                                             |

#### Emits

No component emits on this part. Native bubbling listeners are not additional component emits.

#### Slots

| Default-slot field | Reka type       | Frame availability                             |
| ------------------ | --------------- | ---------------------------------------------- |
| `modelValue`       | `boolean`       | Internal; not passed to the Frame caller slot. |
| `state`            | `"on" \| "off"` | Internal; not passed to the Frame caller slot. |
| `pressed`          | `boolean`       | Internal; not passed to the Frame caller slot. |
| `disabled`         | `boolean`       | Internal; not passed to the Frame caller slot. |

#### Data attributes

| Attribute       | Values/presence         | Meaning                                                   |
| --------------- | ----------------------- | --------------------------------------------------------- |
| `data-state`    | `on \| off`             | Pressed state; aria-pressed supplies accessibility state. |
| `data-disabled` | `Present when disabled` | Activation disabled.                                      |

### Frame additions

#### Props

| Prop       | Type                    | Required/default | Description                                                                                                                            |
| ---------- | ----------------------- | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `options`  | `readonly SelectItem[]` | Required         | Generated buttons and separators.                                                                                                      |
| `label`    | `string`                | Unset            | Accessible name of Root.                                                                                                               |
| `multiple` | `boolean`               | false            | Passed as an attribute, but Reka has no multiple prop here. Use an array model or forwarded type="multiple" to select multiple values. |

#### Emits

No additional Frame-only events; see the part tables for declared or forwarded events.

#### Slots

No public content slots; all internal children are generated.
