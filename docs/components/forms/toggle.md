# FrameToggle

A button with a boolean pressed state, useful for commands such as bold formatting.

## Features

### Anatomy

```text
FrameToggle
Toggle (button by default)
└─ Frame default slot (fallback: label prop)
```

Caller attributes/class/style reach Toggle’s button by default. Frame consumes its default slot without passing through Reka’s scoped fields. These Reka parts are internal composition, not separately exported Frame building blocks.

### Basic usage

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { FrameToggle } from '@frame/core';
import '@frame/core/style.css';

const value = ref(false);
</script>

<template>
  <FrameToggle v-model="value" label="Bold">Bold</FrameToggle>
</template>
```

Load the stylesheet once per application. This component works without a Frame instance.

### Pressed state and content

`modelValue` defaults to false. Frame always binds it to Reka, so `defaultValue` fallthrough does not make the wrapper uncontrolled. Use `v-model` or handle update:modelValue to retain clicks. The default slot replaces the label text but receives no scoped state; read your host model to adapt content.

### Keyboard, accessibility, and forms

The default element is a button with type=button, aria-pressed, and data-state=on/off. Space/Enter activates it using native button semantics. `label` supplies aria-label and fallback visible text; provide an accessible name when using icon-only content. Disabled prevents activation.

Forwarded `as`/`asChild` can alter composition and therefore native keyboard semantics. Root `name`/`required` reach Reka’s checkbox-style form helper when applicable; this is pressed-state submission, not an application command handler or persistence service. Ordinary toggles need no Frame instance.

## APIs

Defaults below are Reka reference defaults unless a Frame override is stated. Declared means a typed Frame prop/event; Forwarded means attribute/listener fallthrough to the named part; Internal means generated by Frame; Absent means not routed or composed. Generic upstream `T`/`AcceptableValue` describes Reka, not a promise of arbitrary option values in Frame.

### Root

#### Props

| Prop           | Reka type            | Reka required/default | Availability | Frame behavior                                                                                                                                                   |
| -------------- | -------------------- | --------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `as`           | `AsTag \| Component` | "button"              | Forwarded    | Element/component used to render this part.                                                                                                                      |
| `asChild`      | `boolean`            | -                     | Forwarded    | Reaches Root, but Frame supplies fixed internal children; no public composition contract for replacing them.                                                     |
| `defaultValue` | `boolean`            | -                     | Forwarded    | Initial uncontrolled value upstream; does not override a supplied controlled model. Frame always supplies modelValue, so this does not initialize wrapper state. |
| `disabled`     | `boolean`            | false                 | Declared     | Frame: `boolean`, false. Disable interaction for this part and its participating descendants.                                                                    |
| `modelValue`   | `boolean \| null`    | -                     | Changed      | Frame: `boolean`, false. Controlled value; updates require the host to retain the emitted value. Boolean-only wrapper; always controlled.                        |
| `name`         | `string`             | -                     | Forwarded    | Submitted/registered field identity.                                                                                                                             |
| `required`     | `boolean`            | -                     | Forwarded    | Participate in the owning form’s required-value constraint.                                                                                                      |

#### Emits

| Event               | Payload            | Availability | Behavior                                                                                          |
| ------------------- | ------------------ | ------------ | ------------------------------------------------------------------------------------------------- |
| `update:modelValue` | `[value: boolean]` | Declared     | Value changed; retain it in host state. Not cancellable. Payload shown is Frame’s public payload. |

#### Slots

| Default-slot field | Reka type       | Frame availability                             |
| ------------------ | --------------- | ---------------------------------------------- |
| `modelValue`       | `boolean`       | Internal; not passed to the Frame caller slot. |
| `state`            | `"on" \| "off"` | Internal; not passed to the Frame caller slot. |
| `pressed`          | `boolean`       | Internal; not passed to the Frame caller slot. |
| `disabled`         | `boolean`       | Internal; not passed to the Frame caller slot. |

#### Data attributes

| Attribute       | Values/presence         | Meaning                                                   |
| --------------- | ----------------------- | --------------------------------------------------------- |
| `data-state`    | `on \| off`             | Pressed state; aria-pressed supplies accessibility state. |
| `data-disabled` | `Present when disabled` | Activation disabled.                                      |

#### Exposed methods

Frame does not defineExpose or forward the internal Reka instance. Do not depend on internal Reka methods/refs through a Frame component ref.

### Frame additions

#### Props

| Prop    | Type     | Required/default | Description                                  |
| ------- | -------- | ---------------- | -------------------------------------------- |
| `label` | `string` | Unset            | Accessible name and fallback button content. |

#### Emits

No additional Frame-only events; see the part tables for declared or forwarded events.

#### Slots

`default`: button content, falling back to label; no scoped payload.
