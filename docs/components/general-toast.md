# Toast

A themed toast powered by Reka UI.

## Features

### Acknowledge a completed save

Activate the example to announce a result. The toast has its own lifecycle; it does not replace Frame’s notification service.

<!-- frame:example id="general-toast.task-0" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameToast, FrameButton } from '@frame/core';
const demoDuration = 8000;
const demoDefaultOpen = false;
const toastOpen = ref(false);
</script>
<template>
<FrameButton @click="toastOpen = true">Show notification</FrameButton>
<FrameToast :title="&quot;Project saved&quot;" :description="&quot;Your changes were saved successfully.&quot;" :duration="demoDuration" v-model:open="toastOpen" />
</template>
```

### Offer a follow-up action

An action can undo a recent host operation. Its accessible alternative explains how to reach the same functionality later.

<!-- frame:example id="general-toast.task-1" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameToast, FrameButton } from '@frame/core';
const demoDuration = 8000;
const demoDefaultOpen = false;
const toastOpen = ref(false);
</script>
<template>
<FrameButton @click="toastOpen = true">Show notification</FrameButton>
<FrameToast :title="&quot;Draft archived&quot;" :description="&quot;The draft moved to the archive.&quot;" :duration="demoDuration" :action-label="&quot;Undo&quot;" :action-alt-text="&quot;Restore the draft from the archive.&quot;" v-model:open="toastOpen" />
</template>
```
