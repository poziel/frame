# Terminal

Terminal sessions with an explicitly supplied backend, side-by-side panes, search, and a session sidebar.

## Features

### Basic usage

The browser example uses a simulated command backend; it does not execute system commands. Supply a backend to run local or remote shells. Closing or moving a Frame view keeps its shells alive; the trash action terminates a session. Sidebar connector lines identify split groups. Right-click a session to rename it or change its color; hover reveals its close button.

<!-- frame:example id="terminal.basic" -->

```vue
import { createTerminal, createTerminalView, Terminal } from '@frame/core/modules/terminal';


const terminal = createTerminal({ backend }); // Supply your application-owned TerminalBackend.
frame.registerView(createTerminalView({
  id: 'terminal', frame, terminal,
}), 'bottom');

// Or place the simple component in any container with a defined height:
// <Terminal :terminal="terminal" profile="pwsh" />
// Keep terminal in the application owner. Dispose it on app teardown.
```

### Composition and configuration

Set sessionId explicitly to override its default. The interactive demo exposes every public property.

<!-- frame:example id="terminal.configured" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { Terminal } from '@frame/core/modules/terminal';
import { createTerminal } from '@frame/core/modules/terminal';
const terminal = createTerminal({ backend }); // Supply your application-owned TerminalBackend. // Dispose on host teardown.
onBeforeUnmount(() => { void terminal.dispose(); });
</script>
<template>
<Terminal :terminal="terminal" :label="&quot;Local terminal&quot;" />
</template>
```
