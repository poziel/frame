# Banner

Custom content above the workspace with independent alignment.

## Features

### Basic usage

Register a Vue component and open the Banner. Left, right, center, and justify alignment determine which regions it spans. Banner content stays app-owned.

<!-- frame:example id="banner.basic" -->

```vue
frame.registerBanner({ id: 'review', label: 'Review', component: ReviewBanner });
frame.openBanner();
```

### Composition and configuration

Set titleText explicitly to override its default. The interactive demo exposes every public property.

<!-- frame:example id="banner.configured" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameShell } from '@frame/core';
import { createFrame } from '@frame/core';
const frame = createFrame();
onBeforeUnmount(() => { frame.dispose(); });
</script>
<template>
<FrameShell :frame="frame" :title-text="&quot;Example&quot;">
  <template #default><span v-text="&quot;Example content&quot;" /></template>
</FrameShell>
</template>
```
