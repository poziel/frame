# Buttons

One button family for quiet actions, outlined actions, and primary actions.

## Features

### Emphasize the next step

A primary action gives the next step in a form or workflow clear visual emphasis.

<!-- frame:example id="buttons.primary-action" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameButton } from '@frame/core';

</script>
<template>
<FrameButton :variant="&quot;primary&quot;" :icon="&quot;check&quot;">
  <template #default><span v-text="&quot;Create project&quot;" /></template>
</FrameButton>
</template>
```

### Offer a secondary action

Keep an alternative action available without giving it the same emphasis as the primary step.

<!-- frame:example id="buttons.secondary-action" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameButton } from '@frame/core';

</script>
<template>
<FrameButton :variant="&quot;secondary&quot;">
  <template #default><span v-text="&quot;Save draft&quot;" /></template>
</FrameButton>
</template>
```

### Keep a utility action quiet

A ghost button fits frequent utility actions inside toolbars and content views.

<!-- frame:example id="buttons.quiet-action" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameButton } from '@frame/core';

</script>
<template>
<FrameButton :variant="&quot;ghost&quot;" :icon="&quot;refresh&quot;">
  <template #default><span v-text="&quot;Refresh preview&quot;" /></template>
</FrameButton>
</template>
```

## APIs

<!-- frame:generated api="buttons" -->

### FrameButton

Source: `packages/core/src/components/actions/FrameButton.vue`

#### Properties

| Name               | Type                                                  | Default  | Description                                                                        |
| ------------------ | ----------------------------------------------------- | -------- | ---------------------------------------------------------------------------------- |
| `tooltip`          | `string \| false \| undefined`                        | Omitted  | Tooltip text; false disables it. When omitted, the native title attribute is used. |
| `tooltipPlacement` | `"top" \| "bottom" \| "left" \| "right" \| undefined` | Omitted  | Preferred tooltip side; positioning falls back when space is limited.              |
| `variant`          | `"ghost" \| "primary" \| "secondary" \| undefined`    | "ghost"  | Visual treatment applied to the button.                                            |
| `label`            | `string \| undefined`                                 | Omitted  | Text used as fallback content when the default slot is omitted.                    |
| `icon`             | `string \| undefined`                                 | Omitted  | Icon displayed before button content.                                              |
| `disabled`         | `boolean \| undefined`                                | false    | Disables native button activation.                                                 |
| `type`             | `"button" \| "submit" \| "reset" \| undefined`        | "button" | Native button behavior within a form.                                              |

#### Events

| Name    | Parameters          | Return type | Description                         |
| ------- | ------------------- | ----------- | ----------------------------------- |
| `click` | `event: MouseEvent` | `void`      | Native click event from the button. |

#### Slots

| Name      | Parameters | Return type  | Description                                                                   |
| --------- | ---------- | ------------ | ----------------------------------------------------------------------------- |
| `default` | `None`     | `VNodeChild` | Button content; replaces the label fallback while retaining the leading icon. |
| `tooltip` | `None`     | `VNodeChild` | Custom tooltip content; replaces the tooltip text.                            |

#### Exposed API

| Name      | Parameters | Return type                      | Description                                                                           |
| --------- | ---------- | -------------------------------- | ------------------------------------------------------------------------------------- |
| `element` | `None`     | `HTMLButtonElement \| undefined` | Native button element, undefined before mounting; refs unwrap on the public instance. |
| `focus`   | `None`     | `void`                           | Focuses the native button when mounted.                                               |
