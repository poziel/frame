# Views And Sections

App-owned views that move between sidebars, panels, and nested collections.

## Features

### Basic usage

A view can hold custom content or child views. Collections share height between expanded sections and preserve preferred sizes. Drag policies control which views may move.

<!-- frame:example id="views.basic" -->

```vue
frame.registerView({ id: 'collection', label: 'Collection', children: [{ id: 'outline', label: 'Outline', component: Outline }] }, 'primary');
```

### Visual variants

Set region explicitly to override its default. The interactive demo exposes every public property.

<!-- frame:example id="views.configured" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { SidePanel } from '@frame/core';

</script>
<template>
<SidePanel :title="&quot;Example dialog&quot;" :region="&quot;secondary&quot;">
  <template #default><span v-text="&quot;Example content&quot;" /></template>
</SidePanel>
</template>
```
