# Modals

Movable, resizable dialogs within the workbench.

## Features

### Basic usage

Open a registered Vue component with frame.openModal. The modal traps focus, closes on Escape, and supports maximize/restore. Set createFrame({ modal: { contentPadding: 16, width: 480, height: 280 } }) for application defaults. Override contentPadding with 0 for edge-to-edge content; set draggable, resizable, or maximizable to false independently. Supply footer and footerProps for application-owned bottom actions. Background content becomes inert while a modal is active.

<!-- frame:example id="modals.basic" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameModal, FrameShell } from '@frame/core';
import { createFrame } from '@frame/core';
const frame = createFrame();
onBeforeUnmount(() => { frame.dispose(); });
</script>
<template>
<FrameShell :frame="frame">
<FrameModal :title="&quot;Example dialog&quot;">
  <template #default><span v-text="&quot;Example content&quot;" /></template>
</FrameModal>
</FrameShell>
</template>
```

### Composition and configuration

Set active explicitly to override its default. The interactive demo exposes every public property.

<!-- frame:example id="modals.configured" -->

```vue
<script setup lang="ts">
import { h, ref, shallowRef, onBeforeUnmount } from 'vue';
import { FrameModal, FrameShell } from '@frame/core';
import { createFrame } from '@frame/core';
const frame = createFrame();
const demoActive = false;
onBeforeUnmount(() => { frame.dispose(); });
</script>
<template>
<FrameShell :frame="frame">
<FrameModal :title="&quot;Example dialog&quot;" :active="demoActive">
  <template #default><span v-text="&quot;Example content&quot;" /></template>
</FrameModal>
</FrameShell>
</template>
```
