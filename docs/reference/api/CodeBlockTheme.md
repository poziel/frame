# CodeBlockTheme

Runtime enum containing every theme bundled with the installed Shiki version.

## Usage

Import the enum from core and pass a member to FrameCodeBlock. codeBlockThemeOptions supplies labels and light/dark metadata for a theme selector. Theme modules load only when selected.

```typescript
import { CodeBlockTheme } from '@frame/core';
const theme = CodeBlockTheme.DarkPlus;
```
